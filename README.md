# reef-metrics.com

The website for **Wavie by ReefMetrics**, an automated reef water tester: [www.reef-metrics.com](https://www.reef-metrics.com)

A static site served by GitHub Pages behind Cloudflare. Pushing to `main` deploys it.

| Page | File |
|---|---|
| Home and Beta Kit pre-order | `index.html` |
| What's inside (scroll tour, parts, lighting, size) | `features.html` |
| Updates and planned features | `updates.html` |
| Questions | `questions.html` |
| Pre-order Terms, Refund and Warranty, Privacy | `terms.html`, `warranty.html`, `privacy.html` |
| Contact, thank-you, 404 | `contact.html`, `thank-you.html`, `404.html` |

Shared pieces live in `assets/` (styles, scripts, images, render sequences) and `partials/` (nav and footer).
